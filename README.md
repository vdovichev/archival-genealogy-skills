# Архивный генеалогический поиск — навыки для ИИ-ассистента

*Skills for archival genealogy research in Eastern Europe (Russia, Belarus, Lithuania,
Ukraine, Latvia, Poland): methodology, a catalogue of 117 sources, connector protocols,
handwriting palaeography (Cyrillic скоропись + Polish/Latin), and Python tooling.
Documentation in Russian.*

Два независимых скилла, упакованных из практики реальных исследований по разным
сословиям и конфессиям Восточной Европы. Личные данные исследований не включены.

| Скилл | Про что |
|---|---|
| `archival-genealogy` | методология поиска, карта источников по странам, рецепты доступа к архивным API и порталам, ловушки, порядок работы, готовый шлюз для ассистента в браузере |

**Что значит «источник» в карте.** Считаются не домены, а точки входа: 2 семейства архивных
АИС (по одному протоколу запросов на десятки региональных архивов), ~6 порталов с разобранным
API, 7 типов именных баз XX в., 9 типов индексов и карт, контуры Литвы/Беларуси/Украины/
Латвии/Польши. Всего ~39 позиций и 25 готовых HTTP-запросов. Конкретные адреса намеренно
не перечислены — они меняются, а протокол движка переносится на любую новую установку.
| `skoropis` | чтение рукописей XVI–XVIII вв.: кириллическая скоропись + латинская/польская |

## Шесть уровней доступа

С навыком работают по-разному, и потолок зависит не от него, а от того, что есть у вас:

| Ур. | Что есть | Потолок |
|---|---|---|
| 1 | обычный чат: веб-поиск и загрузка страниц | разведка, маршрут поиска, источники, отвечающие на GET |
| 2 | агент с оболочкой, Python и сетью | все открытые API, полнотекст по OCR, пакетная обработка книг |
| 3 | + узел в нужной стране | снимается блокировка по географии IP — частая причина ложного «источник мёртв» |
| 4 | + регистрации и сессии архивов | **образы дел**, а не только описи |
| 5 | + государственная авторизация | закрытые читальные залы, официальные запросы, записи ЗАГС |
| 6 | + оплата | неоцифрованное: заказ копий по шифру, работа архивиста на месте |

Каждый уровень включает предыдущие. Подробно — раздел 0 в
[`archival-genealogy/SKILL.md`](archival-genealogy/SKILL.md). Начинать имеет смысл
с первого: половина находок делается там, где платить не нужно.

⚠️ Уровни 5 и 6 — действия человека: заявление подписывает и оплату делает владелец
исследования, ассистент готовит текст запроса, шифр и смету.

## Где что работает

Скиллы — переносимый формат (папка + `SKILL.md` с описанием), но среда решает, что из
них исполнимо:

| Среда | Текст навыка | Образы (`archimg`, `glyphbank`) | Обращение к источникам |
|---|---|---|---|
| терминальный агент с оболочкой | да | да | да, `archnet.py` целиком |
| ассистент в браузере (веб-поиск + загрузка страниц) | да | да, если в песочнице есть Pillow | **да, но только GET** — см. `NOCODE.md` |
| чат без инструментов | да | нет | нет |

Инструменты переписаны на Python со стандартной библиотекой и Pillow: ни ImageMagick, ни
poppler, ни `curl` не нужны.

**Про браузер отдельно.** Песочница исполнения кода обычно без сети, зато у самого ассистента
есть загрузка страниц — то есть GET без своих заголовков и без тела запроса. Этого хватает
для доброй половины источников: движки областных архивов, историческая библиотека,
веб-архив CDX, карточки документов и **OAI-PMH порталов оцифровки** (чистый GET-вход
в коллекцию, работает даже там, где поиск сделан через POST). Что через GET не даётся —
полнотекст по OCR, фасеты, базы с сессией — навык оформляет готовой командой для среды
с оболочкой. Таблица проверенных адресов — в `archival-genealogy/NOCODE.md`.

## Установка

Скопировать нужные папки в директорию скиллов:

```bash
cp -r archival-genealogy ~/.claude/skills/
cp -r skoropis          ~/.claude/skills/
```

Скиллы подхватываются по описанию в `SKILL.md` — отдельной настройки не требуется.

## Чего в пакете нет

- персональных данных, имён исследуемых родов и заказчиков;
- учётных данных, кук, токенов и адресов конкретных машин;
- готового банка вырезанных глифов (он собирается по инструкции в `ALPHABET.md` §5
  из общедоступных палеографических таблиц);
- конкретных доменов платных и полузакрытых сервисов — вместо них описаны **типы**
  источников и способы их распознавания, чтобы приём переносился на любой регион.

## Принцип, на котором держится всё остальное

В родословную идёт только подтверждённое документом. Гипотеза остаётся гипотезой.
Отрицательный результат записывается наравне с находкой — он закрывает направление
и экономит недели.


## Правила обращения с источниками

Навык устроен **на чтение**: запросы только поисковые, ничего не создаётся и не изменяется
на стороне архива. Это не техническое ограничение, а условие работы с чужими системами.

- не выгружать коллекции пачками, не бить по одному адресу параллельными потоками;
- уважать `robots.txt` и условия использования конкретного портала;
- личные данные живущих людей и заказчиков исследования не публиковать;
- сведения о репрессированных, погибших и военнопленных — использовать для установления
  родства, а не для составления списков о людях.
