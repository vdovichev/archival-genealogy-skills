# Начертания, ловушки, лигатуры, цифирь

## 1. Буква ≠ современный вид

| буква | как выглядит в скорописи |
|---|---|
| **а** | альфа ИЛИ **g-образная с петлёй вниз** (путается с «д») |
| **в** | **двугорбая «m»/«п»**, «в»-петля, ω-подобная; часто с двумя поперечинами |
| **г** | **«2»-образная** |
| **ч** | тоже **«2/4»-образная** — «г» и «ч» вне контекста неразличимы |
| **д** | Δ, **g/з-образная с хвостом вниз**, ∂; «ДВ» = двойная петля-«восьмёрка» |
| **к** | в середине слова — **две палочки «ıı»** (как «и»/«п»); заглавная K/R-образная |
| **т** | **трёхногое «m»** ИЛИ выносное с **длинной перекладиной**, тянущейся на полслова и «зачёркивающей» соседей |
| **ь** | **«6»** |
| **ъ** | 8-петля / ϐ |
| **ѣ** | мачта с петлёй + перекладина («+б», «тб») |
| **ы** | «6ı / 8ı» |
| **з** | «3» ИЛИ **длинный диагональный спуск с петлёй** |
| **ѧ / я** | альфа-образная с крюком |
| **ю** | Є-образная / «Іо» |
| **ѳ (фита)** | круг с **ДИАГОНАЛЬЮ/петлёй** сквозь. Горизонталь сквозь круг ≠ фита: это перекладина соседнего выносного «т» |
| **ȣ (ук = у)** | большая дуга + вертикали-минимы |
| **у** | ν/γ-образная с петлёй |
| **ѿ (от)** | ω + выносное «т» (размашистая дуга-перекладина сверху) |
| **ѱ** | симметричный «кубок»: две дуги вверх + **прямой стержень вниз**; в русских документах встречается почти только в датах |

## 2. Выносные буквы

Ищутся **НАД строкой**; их перекладины не считать зачёркиванием соседей.
Различие «петля В строке» ↔ «петля ВЫНЕСЕНА» решает судьбу целых версий.
Выносная читается **вдвойне** (сама + ъ/ь): выносное «д» = «дь», «х» = «хъ», «л» = «лъ».
Вверх выносится целое слово, вниз — целый слог.

**Рогулька** — угловатый крючок над строкой — это `л` или `н` с еровым знаком.
Критерий различения: у «н» знак **круглый, без перелома**, у «л» — **острее и согнутее**.

## 3. Лигатуры (частые пары)

`АВ` = α + **вынесенная** 8-петля · `АД` = α + ꝺ̑ · `АТ` = α + вынесенное «т» ·
`ОВ` = о + в̑ → окончание «-овъ» · **`ОД` = стопка двух петель** · `ОГО` = стопки петель ·
`БО` = δ8 · `ТѢ` = m + Ᏸ · `ТЪ` = π + ȝ · `МЪ` = ʍ + в̑

## 4. Цифирь (даты и числа в полях)

```
А=1 В=2 Г=3 Д=4 Е=5 Ѕ=6 З=7 И=8 Ѳ=9 І=10 К=20 Л=30 М=40 Н=50 Ѯ=60 О=70 П=80 Ч=90
Р=100 С=200 Т=300 У=400 Ф=500 Х=600 Ѱ=700 Ѡ=800 Ц=900
```
- число всегда **под титлом**; тысячи — знак `҂`;
- пример: `҂аѱкв` = 1722;
- **Ѱ (700) в датах читается как «17..»** — тысячи писец часто опускает;
- ⚠️ год от Сотворения мира: из 7132 вычесть 5508 (после сентября — 5509);
  в документах год пишут **без тысяч**: «во 132-мъ году» = 7132 = 1624;
- ⚠️ титло над группой букв — сильный признак числа, но проверять слот: имя в колонке
  имён числом не бывает.

## 5. Как собрать банк начертаний

Банк — это отдельные вырезанные глифы, разложенные по рядам-буквам, чтобы монтировать
их рядом со спорным местом в одном масштабе.

1. Взять опубликованные таблицы скорописи (сводные таблицы начертаний и соединений,
   учебные пособия по палеографии) и/или **азбуку из учебника скорописи**.
2. Нарезать каждую строку таблицы на отдельные PNG: `main_<NN>_<вариант>.png`,
   где `NN` — номер ряда-буквы (00 = А, 01 = Б, … по порядку кириллицы с юсами и фитой).
3. Собрать контактный лист с подписями, чтобы держать весь алфавит перед глазами:
```bash
names=(А Б В Г Д Е Ж Ѕ З И І К Л М Н О П Р С Т У Ф Х Ѡ Ц Ч Ш Щ Ъ Ы Ь Ѣ Ю Я Ȣ Ѱ Ѳ Ѵ)
for r in $(seq 0 37); do rr=$(printf "%02d" $r)
  montage main_${rr}_*.png -tile x1 -geometry 110x110+4+4 -background white miff:- |
  convert - -bordercolor white -border 6 -background '#eef' label:"${names[$r]}" +swap \
    -gravity west -append miff:- > row_$rr.miff
done
montage row_*.miff -tile 2x19 -geometry +6+6 -background gray95 -gravity west allrows.png
```
4. Отдельно завести банк **соединений** (лигатур) — он нужен чаще, чем банк букв.

## 6. Учебная литература

- Учебные курсы русской палеографии начала XX в. содержат: азбуку начертаний,
  условные знаки и титла, цифирь, **таблицы факсимиле с транскрипцией** (главное!)
  и алфавитный указатель слов.
- Ценность таблиц с транскрипцией в том, что они дают **целые ходовые формулы**,
  а сыплется чтение именно на формулах, а не на отдельных буквах.
- Сканы таких изданий лежат в открытых электронных библиотеках; при выкачке из
  IIIF-просмотрщиков полный размер берётся регионами (квадранты + сшивка), потому что
  обычный экспорт часто ограничен по ширине.
