# Инструменты навыка (Python, без внешних бинарников)

| Файл | Что делает | Зависимости |
|---|---|---|
| `archimg.py` | подготовка образа: кроп, синий канал против водяного знака, уровни, резкость, **пояса строки** (`bands` — верхний слой выносных отдельно от тела) | Pillow; PyMuPDF для PDF |
| `glyphbank.py` | банк начертаний писца: нарезка эталонов (`cut`), контактный лист (`sheet`), **сравнение спорного глифа с кандидатами в одном масштабе** (`cmp`), счёт вертикальных штрихов (`strokes`) | Pillow |

```bash
# 1. подготовить строку и прочитать её ДВУМЯ слоями
python3 scripts/archimg.py bands page.jpg line12 --line 1840,180 --x 300 --w 2600
#    сначала смотреть line12_up.png (выносные: «де»=день, «зу»=указу, «-го», «-мъ»),
#    только потом line12_base.png

# 2. посчитать штрихи, ПРЕЖДЕ чем называть слово
python3 scripts/glyphbank.py strokes glyph.png        # 2 → «к», 3 → «ск», не «ш»

# 3. собрать эталоны из БЕССПОРНЫХ слов той же страницы и сравнить
python3 scripts/glyphbank.py cut page.jpg bank/ --boxes "a:300,400,120,140; r:960,400,120,140"
python3 scripts/glyphbank.py cmp cmp.png glyph.png bank/a.png bank/r.png
```

Порядок не произвольный: `bands` → `strokes` → `cmp`. Он лечит три хронические ошибки —
пропуск выносных, чтение «ск» как «ш» и подстановку словарной догадки вместо чтения.

⚠️ Эталон, взятый из спорного слова, — круг: результат недействителен.
