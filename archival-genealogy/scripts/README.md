# Инструменты навыка (Python, без внешних бинарников)

Написаны на Python вместо `convert`/`montage`/`pdftoppm`/`curl`, чтобы приёмы работали
и там, где ImageMagick с poppler не установлены — в песочнице веб-чата, в контейнере
исполнения кода, на чужой машине.

| Файл | Что делает | Зависимости |
|---|---|---|
| `archimg.py` | образы и PDF: рендер страниц, кроп, синий канал, уровни, монтаж, контактный лист, приём «колонка деревни», разрез разворота, пояса строки | Pillow; PyMuPDF только для PDF |
| `archnet.py` | коннекторы поиска: движки «Архивный фонд» и «КАИСА», литовский портал оцифровки, веб-архив CDX, проверка доступности | только стандартная библиотека |
| `kaisa.py` | личный кабинет «КАИСА»: **объём оцифровки дела до скачивания**, поиск по шифру, карта незнакомого дела пробами, выгрузка кадров | стандартная библиотека + `curl`, `xargs` |
| `registry_audit.py` | перепроверка реестра персон: строки без шифра, `[Д]` без образа, отождествление без основания, дубли, несходящаяся арифметика возрастов | только стандартная библиотека |
| `overview_pages.py` | обзорная сетка целых кадров: структура незнакомого дела, листы со списками | Pillow |
| `zags_digest.py` | дайджест актовых книг ЗАГС: шапка (сельсовет) + фамилия ребёнка, сетка 3×4 (`RECIPES.md`) | Pillow |
| `headers_scan.py` | каждый N-й кадр — только строка шапки акта: где в книге начинается нужный сельсовет | Pillow |
| `find_dividers.py` | листы-разделители в папке кадров (почти пустой центр, рамку сканера игнорирует) | Pillow, numpy |
| `notariat.py` | реестр наследственных дел ФНП: проверка гипотез по **полному** ФИО, режим шаблона `--pattern` | стандартная библиотека + `curl` |

```bash
python3 scripts/archimg.py --help
python3 scripts/archnet.py --help
python3 scripts/registry_audit.py РОД-PERSONS-REGISTRY.md   # перед сдачей результата
```

## Что где работает

| Среда | `archimg` | `archnet` | `kaisa` |
|---|---|---|---|
| терминал / агент с оболочкой | да | да | да |
| контейнер исполнения кода без сети | да (если есть Pillow) | нет — запросы не выйдут наружу | нет |
| чат без исполнения кода | нет | нет — навык работает как справочник | нет |

Отсутствие сети — не поломка: в такой среде скилл подсказывает, **какой именно запрос**
выполнить, а выполняется он там, где сеть есть.

## Типовые связки

```bash
# книга PDF → страницы → просмотр колонки деревни на десятке разворотов
python3 scripts/archimg.py pdf book.pdf pages/ --pages 1-40 --dpi 150
for f in pages/*.png; do python3 scripts/archimg.py column "$f" "col/$(basename $f)"; done
python3 scripts/archimg.py montage cols.png 'col/*.png' --tile 5x2 --height 900 --label

# незнакомая книга: найти секции по нарисованным итоговым сеткам
python3 scripts/archimg.py sheet pages/ sheet.png --per 6

# спорное слово: снять водяной знак и увеличить
python3 scripts/archimg.py prep page.jpg word.png --crop 1200,830,600,260 \
        --channel B --width 2000 --levels 9,73 --sharpen

# поиск дела в областном архиве и в литовском портале
python3 scripts/archnet.py af https://<архив> "Такая-то волость метрические книги"
python3 scripts/archnet.py epav "<топоним>" --fulltext

# кабинет КАИСА: сперва объём оцифровки, потом карта дела, и только потом выгрузка
python3 scripts/kaisa.py find <хост> "Ф. N Оп. N Д. N"        # -> objectId
python3 scripts/kaisa.py digi <хост> <objectId> [...]          # кадров РЕАЛЬНО снято
python3 scripts/kaisa.py probe <хост> <objectId> --step 100 --out map/
python3 scripts/kaisa.py pull  <хост> <objectId> out/ --from 656 --to 676 --size 4
```

Порядок в связке КАИСА обязателен: `digi` до всего остального. «Кадры» в карточке
каталога — это листы единицы хранения, и планировать по ним закачку значит закладываться
на объём, которого в оцифровке нет (`PITFALLS.md` §7). Пустой ответ любой команды чаще
всего означает не отсутствие прав, а протухший за сутки токен — скрипт говорит об этом сам.

⚠️ `archnet.py` и `kaisa.py` только читают. Ничего не создают, не изменяют и не удаляют на
стороне источника — это жёсткое правило работы с чужими системами. Заказ копий, подача
требований и оплата абонемента — действия человека, не скрипта.


## Аудит реестра

```bash
python3 scripts/registry_audit.py РОД-PERSONS-REGISTRY.md --root .
```
Возвращает код 1, если есть ошибки — годится как проверка перед тем, как показывать
родословную человеку. Проверяет **форму**: наличие шифра и образа, обоснованность
отождествлений, дубли, сходимость возрастов между ревизиями. Правду он не проверяет —
выборочная сверка фактов с образами делается руками (`REGISTRY.md` §5).
