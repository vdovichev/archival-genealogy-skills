# Технические рецепты

> **Инструменты.** Всё, что ниже показано командами оболочки, продублировано
> Python-скриптами в `scripts/` — они не требуют ImageMagick, poppler и curl
> и работают в песочнице исполнения кода: `python3 scripts/archimg.py --help`,
> `python3 scripts/archnet.py --help`. Соответствие приёмов и команд — `scripts/README.md`.

Проверенные приёмы доступа, скачивания и просмотра. Все команды — POSIX shell + ImageMagick +
poppler-utils + python3.

---

## 1. Мёртвый домен и исчезнувшие файлы — Wayback CDX

Ссылка из каталога ведёт на сайт, которого больше нет в DNS. Это **не тупик**:

```bash
curl "http://web.archive.org/cdx/search/cdx?url=<домен>&matchType=domain\
&output=text&fl=original,timestamp,statuscode&collapse=urlkey\
&filter=statuscode:200&limit=2000"

curl -L "https://web.archive.org/web/<timestamp>id_/<url>" -o file.pdf
pdftotext -layout file.pdf file.txt
```
- `matchType=domain` показывает **всё**, что архив когда-либо взял с домена — включая файлы,
  ссылок на которые уже нигде нет;
- суффикс `id_` в URL отдаёт **оригинальный файл** без обёртки Wayback;
- ⚠️ CDX иногда отдаёт 504 — просто повторить;
- ⚠️ **не качать параллельно**: 4 потока получают бан и половину ошибок. Только
  последовательно, `sleep 2–3` между файлами.

Так восстанавливаются волонтёрские транскрипции приходских книг, выложенные когда-то
школами, краеведами и частными сайтами.

## 2. SPA-портал: найти настоящий бэкенд

Симптом: любой `/api/...` путь отдаёт 200 и **один и тот же HTML** (оболочку приложения),
`json.load` падает на первом символе.

```bash
curl -sSL https://<host>/ -o page.html
grep -o 'src="[^"]*\.js"' page.html            # найти main.<hash>.js
curl -sSL https://<host>/main.<hash>.js -o main.js
grep -oE '"/[a-zA-Z0-9_/{}.-]*(api|search|internal)[a-zA-Z0-9_/{}.-]*"' main.js | sort -u
grep -oE '.{0,40}serverUrl.{0,120}' main.js | sort -u    # базовый префикс + маршруты
```
Из бандла достаются: базовый префикс API, точные пути, имена полей запроса.
Дальше обычный `POST` с `Content-Type: application/json`.

## 3. Большие файлы с облачных дисков

Обычная ссылка `uc?export=download&id=…` на файлах >100 МБ возвращает HTML
«Virus scan warning». Надо вынуть из него токен и запросить:
```bash
uuid=$(grep -o 'name="uuid" value="[^"]*"' warn.html | sed 's/.*value="//;s/"//')
curl -L "https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t&uuid=$uuid" -o file.pdf
```

## 4. Ложная недоступность: TLS вместо блокировки

`curl` возвращает **000** на государственном ресурсе. Это чаще всего **сертификат
национального УЦ**, отсутствующего в стандартном CA-bundle, а не блокировка.
Симптом: `openssl s_client` → `unable to get local issuer certificate`.
**Лечение:** `curl -k` (или доустановка корневого сертификата).

👉 Общее правило: **проверять TLS отдельно от сети**, прежде чем записывать ресурс в мёртвые.

---

## 5. Асимметрия маршрутов

Доступность зависит от того, из какой страны идёт запрос. Один и тот же портал может
открываться с машины в одной юрисдикции и молчать с другой — и наоборот.
Прежде чем чинить коннектор или объявлять портал мёртвым — **прогнать с обеих точек**.
Практический вывод: держать под рукой два выхода (например, SSH-туннель `ssh -D`
и локальный curl) и вести таблицу «хост → откуда открывается».

## 6. Рендер и просмотр книг

```bash
pdfinfo book.pdf | head                        # число страниц, разворот или страница
pdftoppm -f N -l N -r 110 -jpeg -singlefile book.pdf out/pg-N
pdftoppm -r 150 -jpeg book.pdf out/p           # 150 dpi: разворот ~5000×4000, текст читаем
convert p-NN.jpg -resize 2000x -normalize view.jpg
```

**Определить геометрию ДО чтения:** `identify` на файле **из середины** дела, а не на первом
(первый — обложка, у неё другой размер). Отрендерить один кадр целиком и глазами посчитать
страницы. Признак разворота — ландшафтная пропорция и линия сгиба посередине.
Симптом ошибки: «пропуски» в сквозной нумерации записей при подряд идущих кадрах —
значит читается не весь лист.

**Обзор большой книги без указателя:**
```bash
# верхние полосы всех разворотов = хронология книги
convert p-NN.jpg -crop 100%x8%+0+40 +repage top-NN.png
montage top-*.png -tile 1x28 -geometry +2+2 years.jpg
# титулы десятка дел разом
montage title-*.jpg -tile 3x3 -geometry +6+6 titles.jpg
```

## 7. 🔑 Поиск по колонке деревни (главный приём для метрик XIX в.)

В приходских книгах XIX в. слева от каждой записи стоит **название деревни** и номер записи.
Текст читать не нужно — достаточно вырезать левую колонку каждой полустраницы:

```bash
W=$(identify -format %w pg.jpg); H=$(identify -format %h pg.jpg)
HW=$((W/2)); CW=$((HW*24/100))                  # 24% полуширины
convert pg.jpg -crop ${CW}x${H}+0+0    +repage -resize x1500 col-L.png
convert pg.jpg -crop ${CW}x${H}+${HW}+0 +repage -resize x1500 col-R.png
montage col-*.png -tile 10x2 -geometry +6+6 -background '#888' mont.jpg
```
Книга в 90 разворотов = **9 монтажей вместо 174 чтений**. На монтаже видно название деревни
вместе с номером записи ⇒ дальше открывается только нужная страница.

Тот же приём работает для любой книги с постоянной левой колонкой (топоним, № двора, сословие).

## 8. Кроп спорного слова

- 🔑 кропать в **нативном** разрешении или увеличивать **≤ ×1.7** (LANCZOS).
  `-resize` вверх размывает рукопись и порождает ложные чтения;
- для рукописей с водяным знаком поверх текста помогает разделение каналов:
  `convert кадр.jpg -channel B -separate -level 9%,73% -unsharp 0x1.4 out.jpg`
  (тёплые чернила темнеют в синем канале, нейтрально-серый знак светлеет);
- кроп задавать **в пикселях** с `+repage`: проценты в ImageMagick прыгают.

## 9. OCR: когда стоит и когда нет

- в системе обычно только `eng`; языковые модели берутся из общедоступных наборов
  `tessdata_fast` и подключаются через `TESSDATA_PREFIX`;
- ⚠️ на скане 250 dpi — **1–2 минуты на страницу**. Если страниц меньше полусотни,
  читать глазами быстрее, чем распознавать;
- рукописи XVII–XVIII вв. OCR **не берёт вообще** — там только чтение (см. скилл `skoropis`);
- машинописные описи XX в. — наоборот, идеальный кандидат: `pdftotext -layout` + `grep`.

## 10. Греп по фамилии: диакритика и варианты

Список «готовых» написаний фамилии **всегда неполон**. Строить **шаблон**, а не перечень:
```
Z[ao][lł][ea][nń][ie][ec]        вместо  Zalenec|Zalency|Załeniec|…
```
- польские, литовские, латышские формы содержат диакритику, которой нет в списке;
- кириллические и латинские формы одного рода ищутся **отдельно**;
- женские формы: `-owa` = замужняя (жена N), `-owna` = дочь N — это разные люди;
- фамилия **рвётся переносом строки** («Petri Elz-|but») — грепать по обеим половинам;
- регулярка по корню промахивается на беглой гласной («сорочк» не ловит «сорочек») —
  проверять на заведомо известном примере.

⚠️ `ugrep` не поддерживает `(?!…)` и падает на `.{0,90}` в юникод-контексте
(«exceeds complexity limits») — сложные шаблоны прогонять через `python3 -c`.

## 11. Сессии и куки пользователя

- когда ресурс требует логина, работать **сессией владельца аккаунта**, переданной им
  добровольно (кука/Bearer), и уничтожать её после работы (`shred -u`);
- никогда не сохранять чужие пароли; кука живёт часы — это достаточно;
- действия, создающие обязательства (заказ, оплата, отправка запроса), выполняет **человек**.
  Автоматизировать можно только обратимое: сбор корзины, поиск, скачивание.

## 12. Проверка «оцифрован ли фонд» одним запросом

Во многих порталах карточка дела достаётся по предсказуемому ID:
```
findById?id=<АРХИВ>_<фонд>_<опись>_<дело>
```
Пустая карточка (все поля `None`) = такого дела в портале нет.
⚠️ **Обязателен контроль**: тот же запрос на заведомо существующем деле должен вернуть данные.
Без контроля «пусто» ничего не доказывает.

## 13. Хранение

- сканы книг — сотни МБ; отработанное выгружать в облако (`rclone`), оставляя рабочее;
- ⚠️ **не хранить в `/tmp`** — эфемерен, теряется между сессиями вместе с уникальными
  копиями из Wayback. Всё найденное сразу класть в постоянную папку рода;
- имена файлов самодокументирующие: `ТИП-ИМЯ-ДАТА-роль-место-источник-лист.jpg`.
